# ADR-0003: Android 앱과 Node MCP의 단일 저장소

- 날짜: 2026-11-02
- 상태: 채택 (2026-11-03, 담당자가 알린 상대 개발자 합의. COM-16 PR에 기록). `mcp/` 부분은 [ADR-0008](0008-embedded-mcp-server.md)로 대체되어 저장소에는 `app/`만 남는다

## 맥락
1차 구조는 Android 앱과 Node MCP 서버가 Bridge 계약으로 묶인다. PoC도 `app/`과 `mcp/`를 한 저장소에 둔다. ADR-0002는 도구 이름·스키마·오류·포트 변경을 양쪽 검사와 함께 같은 PR로 제출하도록 정한다. CI에는 `mcp/`가 생기면 동작하는 `mcp` job이 이미 있다. 이 구조에 대한 두 개발자의 합의 기록은 없었다.

## 결정
`SubHye/Pleos_PA` 한 저장소의 `app/`과 `mcp/`에 둔다. 코드 이전은 COM-19 등 기능별 Issue에서 진행한다.

## 결과
계약 변경을 한 PR에서 검사하고 리뷰할 수 있다. CI는 Android와 Node 검사를 함께 실행한다. 두 패키지가 저장소 이력과 PR 흐름을 공유한다. 독립 배포나 별도 접근 권한이 필요해지면 대체 ADR을 작성한다.
